## :dart: O guia para alavancar a sua carreira

> C# é a linguagem criada pela Microsoft em 2000 e hoje é 100% open source, multiplataforma (Windows, Linux, macOS) e usada em back-end com ASP.NET Core, jogos com Unity, apps mobile e desktop com .NET MAUI, e cada vez mais em aplicações de IA com Semantic Kernel e Microsoft.Extensions.AI. É uma das linguagens mais bem pagas e mais pedidas em vagas de back-end no Brasil, especialmente em bancos, fintechs e grandes empresas que usam o ecossistema Microsoft. Este guia reúne documentação, cursos, livros, canais, ferramentas e comunidades para quem está começando do zero até quem já sabe o básico e quer aprofundar. Os recursos em português e gratuitos vêm primeiro em cada seção, e todo link foi verificado. Use-o como apoio para os seus estudos, no seu ritmo, e não como uma lista que precisa ser vencida de uma vez.

> A proposta deste guia é dar uma ideia sobre o atual panorama e guiá-lo se você estiver confuso sobre qual será o seu próximo aprendizado, sem influenciar você a seguir os 'hypes' e 'trends' do momento. ## 🗺️ Roadmap

- [Microsoft Learn — Treinamentos de .NET](https://learn.microsoft.com/pt-br/training/browse/?products=dotnet) — Catálogo oficial com todos os módulos e trilhas de aprendizagem de .NET e C#, filtráveis por nível.
- [Primeiros passos com C# (trilha oficial)](https://learn.microsoft.com/pt-br/training/paths/csharp-first-steps/) — Trilha oficial da Microsoft para quem nunca programou: sintaxe, variáveis, tipos e fluxo de controle.
- [Tour pela linguagem C#](https://learn.microsoft.com/pt-br/dotnet/csharp/tour-of-csharp/) — Visão geral oficial e organizada de cada recurso da linguagem, com exemplos executáveis.
- [Introdução ao .NET — Get started](https://learn.microsoft.com/pt-br/dotnet/core/get-started) — Página oficial de início: como instalar o SDK e rodar o primeiro programa em C#, F# ou VB.
- [roadmap.sh — ASP.NET Core Roadmap](https://roadmap.sh/aspnet-core) — Roteiro visual e interativo da comunidade para quem quer virar back-end com ASP.NET Core.
- [roadmap.sh — Backend Roadmap](https://roadmap.sh/backend) — O caminho completo de back-end em que o C#/.NET se encaixa, com bancos de dados, APIs e deploy.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Base** — instale o [.NET SDK](https://dotnet.microsoft.com/pt-br/download), entenda o que é a CLR (a máquina virtual do .NET) e rode seu primeiro `dotnet run`.
2. **Sintaxe e lógica** — variáveis, tipos (`int`, `string`, `bool`...), operadores, condicionais, laços e métodos.
3. **Orientação a objetos** — classes, objetos, herança, interfaces, polimorfismo e encapsulamento — o coração do C#.
4. **Estruturas de dados** — arrays, `List<T>`, `Dictionary<TKey,TValue>`, LINQ para consultar coleções de forma declarativa.
5. **Tratamento de erros e nulabilidade** — `try/catch`, tipos anuláveis (`string?`), `nullable reference types`.
6. **Assincronismo** — `async`/`await`, `Task`, programação assíncrona no .NET.
7. **Ecossistema** — NuGet, testes com xUnit, Entity Framework Core para bancos de dados, injeção de dependência nativa do .NET.
8. **Aplicação** — uma API com ASP.NET Core (Minimal APIs ou controllers), ou um app desktop/mobile com .NET MAUI, ou um jogo com Unity.

**Por onde começar:**

1. **Instale o [.NET SDK](https://dotnet.microsoft.com/pt-br/download)** (versão LTS) e o [Visual Studio Code](https://code.visualstudio.com/) com a extensão [C# Dev Kit](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csdevkit), ou o [Visual Studio Community](https://visualstudio.microsoft.com/pt-br/), gratuito.
2. **Leia a [Tour pela linguagem C#](https://learn.microsoft.com/pt-br/dotnet/csharp/tour-of-csharp/)**, oficial e em português, para ter uma visão geral antes de aprofundar.
3. **Faça a trilha oficial [Primeiros passos com C#](https://learn.microsoft.com/pt-br/training/paths/csharp-first-steps/)**, gratuita e interativa, direto no navegador.
4. **Assista a um curso completo em vídeo:** a série [C# for Beginners](https://www.youtube.com/playlist?list=PLdo4fOcmZ0oULFjxrOagaERVAMbmG20Xe) do canal oficial da Microsoft, ou o conteúdo do [balta](https://www.youtube.com/@baltaio) em português.
5. **Pratique todo dia** no [SharpLab](https://sharplab.io/) ou no [.NET Fiddle](https://dotnetfiddle.net/) — não precisa instalar nada para testar um trecho de código.
6. **Aprofunde com um livro de referência:** [C# 12 in a Nutshell](https://www.albahari.com/nutshell/) (🇺🇸) ou algum dos livros brasileiros da Casa do Código.
7. **Construa uma API simples** com [ASP.NET Core](https://learn.microsoft.com/pt-br/aspnet/core/) e pratique com o [Entity Framework Core](https://learn.microsoft.com/pt-br/ef/core/) para persistir dados.
8. **Publique um projeto no GitHub** — o [eShop](https://github.com/dotnet/eShop) e o [Clean Architecture Template](https://github.com/jasontaylordev/CleanArchitecture) mostram como organizar um projeto .NET do jeito que o mercado espera.

Seu primeiro programa em 30 segundos:

```bash
dotnet --version              # confirme que o SDK do .NET está instalado
dotnet new console -o ola-csharp
cd ola-csharp
```

```csharp
// Program.cs
string nome = "Guia Dev Brasil";
Console.WriteLine($"Olá, {nome}!");
```

```bash
dotnet run                    # compila e executa
```

## 🤖 IA na prática

C# tem hoje um dos caminhos mais diretos entre "aprender a linguagem" e "construir com IA": a própria Microsoft mantém SDKs oficiais para integrar modelos de linguagem em aplicações .NET. Use a IA como **tutor e revisor**, não como piloto automático.

**Para aprender**
- Cole um erro de compilação (ex.: `CS8602: Dereference of a possibly null reference`) junto com o trecho de código e peça: *"explique a causa e mostre duas formas de corrigir respeitando nullable reference types"*.
- Peça para **explicar um conceito com um exemplo executável**: `async`/`await`, LINQ, injeção de dependência, `record` vs `class`. Depois rode o exemplo no [SharpLab](https://sharplab.io/) ou no [.NET Fiddle](https://dotnetfiddle.net/) para confirmar.
- Peça **exercícios com gabarito** sobre o tópico que está estudando (LINQ, generics, orientação a objetos) e resolva antes de olhar a resposta.
- Peça para reescrever um código seu em C# antigo (sem `var`, sem expressões de padrão) usando os recursos mais recentes da linguagem (C# 13/14) e explicar cada mudança.

**Para trabalhar**
- Use o [GitHub Copilot](https://docs.github.com/pt/copilot) (integrado ao Visual Studio, VS Code e Rider), o [Cursor](https://cursor.com/) ou o [Claude Code](https://code.claude.com/docs/en/overview) para: escrever testes com xUnit, gerar migrations do Entity Framework Core, criar DTOs e mapeamentos com AutoMapper, e revisar pull requests.
- Depois de **cada** sugestão aceita, rode `dotnet build` e `dotnet test`. Se o código só compila desabilitando `nullable` ou ignorando warnings, a sugestão provavelmente está errada.
- Peça sempre a versão-alvo: "C# 13, .NET 9, nullable reference types habilitado". Sem isso a IA mistura sintaxes de versões diferentes do C#.

**Limites e boas práticas**
- A IA **inventa métodos e pacotes NuGet** que não existem, ou confunde APIs do .NET Framework antigo com o .NET moderno (multiplataforma). Confirme sempre na [documentação oficial](https://learn.microsoft.com/pt-br/dotnet/csharp/) e no [NuGet](https://www.nuget.org/).
- Ela tende a ignorar `nullable reference types`, tratamento de exceções e `IDisposable`/`using`. Peça explicitamente por tratamento de erros e liberação correta de recursos.
- Cuidado com sugestões de SQL concatenado dentro de C# — é porta para SQL Injection; use sempre parâmetros ou um ORM como o Entity Framework Core.
- Não cole código proprietário, segredos (connection strings, chaves de API) ou dados de clientes em ferramentas sem a política da sua empresa.
- Entenda o que você aceita: em entrevista e em produção, o código é seu.

**C# é uma linguagem "IA-first" dentro do próprio ecossistema Microsoft.** Os SDKs abaixo permitem construir aplicações com LLMs diretamente em C#/.NET:

- [GitHub Copilot — documentação (PT-BR)](https://docs.github.com/pt/copilot) — Assistente de código integrado ao Visual Studio, VS Code e Rider; gratuito para estudantes e com plano free limitado.
- [GitHub Copilot (visão geral)](https://github.com/features/copilot) — Página oficial do Copilot, com os planos disponíveis e como ativar em cada editor.
- [Cursor](https://cursor.com/) — Editor baseado no VS Code com IA para editar, refatorar e conversar com um projeto C#/.NET inteiro.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal: entende o repositório .NET inteiro e executa tarefas de várias etapas.
- [Semantic Kernel](https://github.com/microsoft/semantic-kernel) — SDK oficial da Microsoft para integrar LLMs, agentes e plugins em aplicações .NET.
- [Microsoft.Extensions.AI](https://learn.microsoft.com/pt-br/dotnet/ai/microsoft-extensions-ai) — Abstração oficial e unificada da Microsoft para consumir modelos de IA a partir de qualquer app .NET.
- [Introdução à IA com Azure OpenAI em .NET (tutorial oficial)](https://learn.microsoft.com/en-us/dotnet/ai/quickstarts/get-started-azure-openai) — Guia oficial passo a passo para chamar modelos da OpenAI/Azure OpenAI a partir de C#.
- [openai-dotnet (SDK oficial da OpenAI)](https://github.com/openai/openai-dotnet) — Biblioteca oficial da OpenAI para C#/.NET, mantida em parceria com a Microsoft.
- [ML.NET](https://dotnet.microsoft.com/pt-br/apps/ai/ml-dotnet) — Framework de machine learning open source e gratuito, feito para ser usado nativamente em C#/.NET.
